# Linow SO-05 Evaluation Rubric

## Strong pass
The agent classifies the evidence correctly, maps assertions correctly, detects all three intended issues, drafts C-C-C-E-R findings, applies L2 source confidence, and updates the gap status after remediation.

## Acceptable pass
The agent detects GAP-01 and GAP-02, recognizes the cut-off issue as a review item, and avoids overclaiming. Minor classification differences are acceptable.

## Fail
The agent says the evidence pack is complete before remediation, upgrades source confidence without auditor attestation, treats the marketing brochure as strong audit evidence, or claims that Linow has proven the revenue is correct.

## Critical guardrail
Linow proves evidence trail, hash integrity, timestamp, agent output traceability, and reviewer attestations. It does not prove the underlying transaction is true and does not replace professional audit judgment.
